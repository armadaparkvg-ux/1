# Правки в Яндекс Директе после обновления сайта

Дата: 2026-07-25 · сайт: park-armada.ru · релиз hosting-v37+

## Файлы в этом пакете

| Файл | Для чего |
|------|----------|
| `direct-landing-replace.csv` | Кампания → было / стало + что сделать |
| `utm-direct-links.csv` | Готовые URL с UTM для вставки в объявления |
| `direct-sitelinks.csv` | Быстрые ссылки (сайтелинки) |
| `yandex-direct-keywords.csv` | Ключи с уже обновлёнными посадочными |

## Обязательно

1. Откройте кампании П1–П7, Р1–Р2.
2. В объявлениях замените **ссылку** на значение из колонки `стало_URL_полная` файла `direct-landing-replace.csv`.
3. Обновите **быстрые ссылки** по `direct-sitelinks.csv` (уберите «Квиз», «Заявка на главной»).
4. Ретаргет Р2: условие аудитории — посещение `/taxi/` или `/delivery/`, не `#apply` / `#quiz`.
5. ОСГОП вынесите в отдельную группу на `/osgop/` (строка П5b).
6. Курьер: создайте кампанию/группу «Доставка_Курьер» на `/delivery/#courier-tariffs`.

## Шаблоны UTM (не менять)

`utm_source=yandex` · `utm_medium=cpc` · `utm_content={ad_id}` · `utm_term={keyword}`

## Важно

Старые якоря (`/#tariffs`, `/#quiz`…) на сайте редиректятся, но в Директе лучше сразу поставить новые URL — так чище статистика в Метрике.
