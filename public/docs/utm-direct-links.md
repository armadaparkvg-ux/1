# Готовые UTM-ссылки для Яндекс Директ

Источник правды: `utm-direct-links.csv`.

Шаблон:
```
?utm_source=yandex&utm_medium=cpc&utm_campaign=<код>&utm_content={ad_id}&utm_term={keyword}
```

`{ad_id}` и `{keyword}` — подставляются Директом автоматически.

| Кампания | utm_campaign | Посадка |
|----------|--------------|---------|
| Подключение | `p1_podklyuchenie` | `/#tariffs` |
| Самозанятый | `p2_samozanyatyj` | `/#tariffs` |
| ИП | `p3_ip` | `/#tariffs` |
| Трудовой | `p4_trudovoj` | `/#labor-contract` |
| ФГИС | `p5_fgis` | `/#services` |
| Бренд | `p6_brand` | `/` |
| Квиз | `p7_quiz` | `/#quiz` |
| Лимит НПД | `p8_limit_npd` | `/blog/limit-npd-2-4-mln/` |
| Статьи | `p9_blog` | `/blog/` |
| РСЯ | `r1_rsya` | `/#quiz` |
| Ретаргет | `r2_retarget` | `/#apply` |

UTM с сайта уходят в текст заявки (форма и квиз).
