# Главная: новая информационная архитектура

Дата: 22.07.2026

## Цель

Не заставлять пользователя читать все условия на одной странице. Главная отвечает на один вопрос: **какое направление нужно?**

## Главная теперь содержит только

1. Первый экран: оффер и контакты.
2. Знакомство с парком: цифры и доверие.
3. Четыре направления:
   - Такси
   - Доставка
   - Лицензия ФГИС
   - ОСГОП
4. Акции и бонусы: приглашение в канал MAX.
5. Контакты.

## Страницы направлений

| Страница | Содержимое |
|---|---|
| `/taxi/` | Классы авто, форматы самозанятый/ИП/трудовой, авторегистрация |
| `/delivery/` | Пеший/авто/мото/грузовой курьер, формы регистрации |
| `/license/` | ФГИС, цена, документы, проверка авто, заявка |
| `/osgop/` | ОСГОП, цена, условия, заявка |

Все новые страницы используют адаптивные WebP-изображения через `next/image`.
