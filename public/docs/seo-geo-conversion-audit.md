## 3. Технические задачи и баги

### Исправлено в этой итерации (код → hosting-v13)
1. **Canonical / sitemap** — trailing slash под static export (`/privacy/` и т.д.)  
2. **robots.txt** — `Disallow: /docs/` (не индексировать CSV аудитов)  
3. **HTTPS 301** включён в `.htaccess`  
4. **Title/description** укорочены под сниппет Яндекса  
5. **Видимый H1** в hero  
6. **Primary CTA** — «Подобрать тариф»; телефон вторичный; мессенджеры/ФГИС — третий ряд  
7. **Iframe форм** открываются по кнопке (не грузят страницу сразу)  
8. **OG JPG 1200×630** вместо SVG  
9. **Таблица сравнения тарифов** `#compare`  
10. **+5 FAQ** под поисковые вопросы  
11. **areaServed** расширен приоритетными регионами в schema  

### Остаётся на стороне владельца / хостинга
| Задача | Зачем |
|--------|--------|
| Загрузить hosting-v13 в `public_html` | Чтобы правки попали на прод |
| Указать **ИНН / ОГРН / юр. название** на `/requisites/` | E-E-A-T, доверие, модерация рекламы |
| Карточка **Яндекс.Бизнес** (зона обслуживания РФ) | Локальные/геосигналы |
| Отзывы реальные (скрин/текст + город) | Конверсия и сниппеты |
| Не публиковать пароли/доступы в чат | Безопасность |

### Мелкие риски (P2)
- Конфликт scroll-lock меню/модалки — мониторить на мобиле  
- MAX без deep-link текста — остаётся копирование в буфер  
- Нет PNG apple-touch icon  
- Тонкие `/privacy` `/offer` — расширить юридическим текстом

## 5. GEO-анализ

Модель бизнеса — **удалённое подключение по РФ**, офиса нет. Это нормально, но для геовыдачи слабо.

| Сигнал | Сейчас | Нужно |
|--------|--------|-------|
| Телефон | Есть | Оставить единый NAP везде |
| Адрес | Нет | Юр. адрес на `/requisites/` (не фейковый офис) |
| Города в тексте | «по всей России» | + блок «Подключаем в …» (топ-города из Метрики) |
| Яндекс.Бизнес | Нет | Создать, зона = регионы работы |
| City-pages | Нет | 5–10 городов после данных Директа |

**Стратегия city pages (не спамить):**  
`/moskva/`, `/krasnodar/`, `/rostov/` — уникальный абзац + FAQ + телефон + «оформление удалённо», без копипаста «такси дешево».
