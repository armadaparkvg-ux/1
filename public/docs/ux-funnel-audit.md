# UX/воронка park-armada.ru — аудит и статус исправлений

Дата: 22.07.2026  
Сайт: https://park-armada.ru

## Целевой путь клиента

```
Знакомство с парком
        ↓
Выбор направления: Такси  /  Доставка
        ↓
Классы заказов (эконом → премиум)  или  тарифы курьера
        ↓
Формат оформления в парке (самозанятый / ИП / трудовой)
        ↓
Сравнение → квиз (если сомневается)
        ↓
Регистрация / заявка в чат
```

## Найденные проблемы → статус

| Проблема | Статус |
|----------|--------|
| Квиз раньше тарифов и направлений | ✅ Исправлено — квиз после оформления |
| Нет развилки Такси / Доставка | ✅ Блок `#directions` |
| Классы Яндекс после тарифов парка | ✅ Классы перед оформлением |
| «Как подключиться» внизу | ✅ Сразу после «О парке» |
| Навигация без сценария | ✅ О парке → Направления → Классы → Оформление → Заявка |
| Hero CTA сразу в квиз | ✅ «Выбрать направление» / «Узнать о парке» |
| Шаги HowTo устарели (начинались с заявки) | ✅ Переписаны под воронку |
| Квиз без доставки/курьера | ✅ Цель «Подключиться курьером» → `/courier/` |
| Видео в середине воронки | ✅ Перенесено после контактов |
| Нет карты шагов на странице | ✅ `FunnelNav` под hero |
| Цели Метрики не размечены в коде | ✅ `trackGoal` + список целей |
| FAQ без такси/доставки | ✅ +2 вопроса |
