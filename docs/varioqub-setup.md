## В кабинете Метрики

1. Метрика → **Вариокуб** → Эксперименты  
2. **Код для сайта** → JavaScript — можно не копировать вручную, код уже вшит  
3. Создайте тестовый АА-эксперимент визуальным редактором (без изменений)  
4. Через время смотрите отчёт — должны появиться визиты по вариантам  

## Проверка в браузере (F12 → Network)

1. `abt.s3.yandex.net/expjs/latest/exp.js` → 200  
2. `uaas.yandex.ru` → 200, в ответе есть параметр `i`  
3. Application → Cookies → есть `_ymab_param`
