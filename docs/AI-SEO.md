# ИИ-SEO для park-armada.ru: что продают, что работает, что внедрили

Дата: 23.08.2026. Ниша: таксопарк, Яндекс Такси / Доставка, Россия.

Короткий вывод: **ИИ не ставит сайт в топ.** Нейроответы Яндекса собираются из обычной выдачи (примерно топ‑20–30). Массовая генерация «контент-заводом» без уникальных фактов парка — риск фильтра, а не shortcut. Имеет смысл автоматизировать технику, перелинковку, индексацию и структуру ответа; тексты — только с фактами «Армады» и человеческой проверкой.

## Что внедрили сейчас (безопасная автоматизация)

1. **IndexNow** — ключ в корне `armadaidx7Kq2Nm9Px4Rt8Wv.txt`. После заливки хостинга: `npm run indexnow`.
2. **`/llms.txt` и `/llms-full.txt`** — карта смыслов для агентов + ссылка на sitemap и RSS. Не обещаем рост позиций из‑за файла.
3. **RSS `/feed.xml`** — обновление контента для агрегаторов и части ИИ-пайплайнов.
4. **robots.txt** — явный Allow основным поисковым и ответным ботам, закрыты `/go/`, `/docs/`, `/api/`.
5. **FAQ в HTML `<details>`** — ответы в исходнике без JS. FAQ+Schema на такси, доставке, ФГИС, ОСГОП.
6. **Answer-first в статьях** — блок «Коротко», оглавление, автор = организация, хлебные крошки, speakable в JSON-LD.
7. **Тематические хабы** — блог сгруппирован: такси / трудовой / доставка / документы / о парке. Перелинковка посадочных со статьями того же кластера.
8. **Генерация манифестов на сборке** — `scripts/write-public-ai-files.mjs` в `build-static.sh`.

## Что сознательно не делаем

- Тысячи AI-страниц и «контент-завод» под Wordstat
- Дверные лендинги «таксопарк в каждом районе»
- Покупка ссылок / накрутка ПФ
- Обещания больничных, отпуска, «всегда первые в поиске»
- Копирование ТЗ Директа в `public/docs/` (не для выдачи)

## Что делать руками после деплоя

1. Залить статику в `/www/park-armada.ru/`.
2. Проверить: `https://park-armada.ru/llms.txt`, `/feed.xml`, `/{ключ}.txt`.
3. `npm run indexnow` (или из папки репозитория после того, как файлы уже на домене).
4. Яндекс Вебмастер: переобход главной, `/taxi/`, `/trudovoj-dogovor/`, `/delivery/`, `/blog/`, sitemap.
5. Включить обход по счётчику Метрики (если ещё не включён).
6. Смотреть запросы в Вебмастере 2–4 недели; новые статьи — только под дыры спроса, с фактами парка.

Директ и органика — разные каналы. Реклама в выдаче не заменяет топ по информационным запросам.
