# Цели Метрики: авторегистрация Fleet

Счётчик: `110811547`

## Почему «проверка перехода» не показывала цель

Клик вёл сразу на `forms.fleet.yandex.ru` (чужой домен).  
Проверка **перехода по страницам** видит только URL вашего сайта.

Теперь кнопка «Авторегистрация» открывает:

`https://park-armada.ru/go/fleet/?channel=courier&type=foot`  
→ (0,25 с) → форма Яндекс Fleet.

Метрика фиксирует визит `/go/fleet/` — это видно в проверке перехода.

---

## 1. Цель по URL (для проверки перехода) — обязательно

Метрика → Цели → Добавить → тип **«Посещение страниц»** / условие URL:

| Название | Условие |
|----------|---------|
| `visit_fleet_go` | url: **содержит** `/go/fleet/` |
| `visit_fleet_courier` | url: **содержит** `channel=courier` |
| `visit_fleet_taxi` | url: **содержит** `channel=taxi` |

Проверка: Цели → выберите `visit_fleet_go` → **Проверить** → на сайте кликните «Авторегистрация» → должно стать «Цель достигнута».

---

## 2. JavaScript-цели (для Директа)

Тип: **JavaScript-событие**. Идентификатор точно как ниже:

| Идентификатор | Когда |
|---------------|--------|
| `click_fleet_form` | любая авторегистрация / открытие iframe |
| `click_fleet_taxi` | такси |
| `click_fleet_courier` | курьер |

Проверка JS-цели: в кабинете выберите именно эту цель → «Проверить» → клик на сайте.  
Не путайте с проверкой «перехода по URL».

---

## 3. Что поставить в Директ

| Кампания | Цель |
|----------|------|
| Курьеры | `visit_fleet_courier` или `click_fleet_courier` |
| Такси | `visit_fleet_taxi` или `click_fleet_taxi` |
| Общий KPI | `visit_fleet_go` / `click_fleet_form` |

---

## 4. После обновления сайта

1. Залейте hosting ZIP в `public_html`.
2. Жёсткое обновление страницы (Ctrl+F5).
3. Инкогнито → `/delivery/#courier-tariffs` → «Авторегистрация» (в той же вкладке).
4. Экран «Переходим к авторегистрации…», URL `/go/fleet/?channel=courier…`.
5. Метрика → Онлайн: страница `/go/fleet/`.
6. Проверка цели `visit_fleet_go`.
