# Цели Метрики: авторегистрация Fleet

Счётчик: `110811547` · сайт шлёт `ym(...reachGoal...)` при клике.

## Создать в кабинете Метрики

Тип цели: **JavaScript-событие**. Идентификатор = имя ниже.

| Идентификатор | Когда срабатывает |
|---------------|-------------------|
| `click_fleet_form` | Любая авторегистрация (такси + курьер) |
| `click_fleet_taxi` | Такси: самозанятый / ИП |
| `click_fleet_courier` | Курьер: пеший / авто / мото / грузовой |
| `click_courier_form` | То же, что курьер (alias) |

Параметры события (в отчётах): `channel`, `type` (`smz`/`ip`/`self`/`foot`…), `action` (`link` | `iframe`).

## Директ

- Кампании такси → конверсия `click_fleet_taxi`
- Кампания курьеров → конверсия `click_fleet_courier`
- Общий KPI → `click_fleet_form`

## Проверка

1. Инкогнито: `/taxi/#formats` или `/delivery/#courier-tariffs`
2. Клик «Авторегистрация» или «Открыть форму на сайте»
3. Метрика → Онлайн / Цели → цель должна появиться
