### Что Директ может и чего не может

- Директ ставит **объявления** в блок над/под органикой. Это **не** позиция сайта в бесплатной выдаче.
- «Сайт всегда в топе по всем запросам» **недостижимо** ни Директом, ни SEO: частотники делят агрегаторы и крупные сети; бюджет конечен; инфозапросы живут статьями и Вебмастером.
- Правильная связка: **Директ = платный топ по целевым коммерческим кластерам** + **органика = Вебмастер + статьи + города**. В этом ТЗ вы настраиваете Директ.

### Запреты в текстах объявлений и на баннерах

- **Не писать** про больничные, отпуск «даём», «официальный отпуск».
- Не обещать «уберём комиссию Яндекса» (комиссия парка и комиссия Яндекса — разные платежи).
- Не обещать аренду авто, офис, работу без гражданства РФ.
- Не обещать авторегистрацию для **трудового** договора.
- Не вести курьерские ключи на `/taxi/` и трудовые — на `/license/`.
- Не использовать старые якоря главной: `/#tariffs`, `/#quiz`, `/#apply`, `/#labor-contract`, `/#services`. На сайте часть редиректится, в Директе ставить **новые URL**.
- Не ставить в объявления: `/go/fleet/`, `/courier/` (редирект), `/docs/`, `/llms.txt`, `/feed.xml`, ключ IndexNow.

### Шаблон UTM (не менять имена параметров)

```
?utm_source=yandex&utm_medium=cpc&utm_campaign=<КОД>&utm_content={ad_id}&utm_term={keyword}
```

Всегда **https**, всегда **закрывающий слэш** у посадок (`/taxi/`, не `/taxi`).  
Якорь (`#formats`) — **после** query: `.../taxi/?utm_...#formats`.

Телефон в визитке: `+7 918 052-10-22`.  
Часы: `8:00–21:00 Мск, ежедневно`.  
Юрлицо в текстах при необходимости: ООО «АРМАДА ДРАЙВЕР».  
MAX канал (акций): `https://max.ru/id235208280463_biz`  
MAX чат заявок и Telegram — только уточнение/сайтлинк, не основная ссылка объявления.

Комиссия парка СМЗ/ИП: **от 1,9%**.  
Трудовой: **3%+300₽ / 5%+100₽ / 6% без ежедневных списаний**. Налог по трудовому платит парк.  
ФГИС: **3 500 ₽ / 5 лет**, обычно 1–3 дня.  
ОСГОП: **3 400 ₽ / год**.

## 5. Ключи и минус-слова

### П4 трудовой (фразовое `"..."` + точные на дорогие)

Ядро: трудовой договор яндекс такси; работа в такси без самозанятости; без ИП; оформление по ТК; 2ндфл такси; деприоритет тип занятости; тип занятости не подтвержден; банкротство такси; 3%+300 такси (осторожно, низкочастотники).

Минуса П4: курьер, пеший, доставка еды, заказать такси, вакансия hh, аренда авто, без гражданства, франшиза парка, скачать про, больничный (не используем в оффере), квиз.

### П2 самозанятый

парковый самозанятый; самозанятый яндекс такси; комиссия 1,9 таксопарк; подключить самозанятого к такси.

Минуса: трудовой договор, без самозанятости, курьер (кроме явного «такси»), пассажирские «заказать».
