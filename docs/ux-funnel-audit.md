# UX/воронка park-armada.ru — профессиональный аудит

Дата: 22.07.2026  
Сайт: https://park-armada.ru

## Целевой путь клиента

```
Знакомство с парком
        ↓
Выбор направления: Такси  /  Доставка
        ↓
Классы заказов (эконом → премиум)  или  тарифы курьера
        ↓
Формат оформления в парке (самозанятый / ИП / трудовой)
        ↓
Сравнение → квиз (если сомневается)
        ↓
Регистрация / заявка в чат
```

## Что было не так (до правки)

| Проблема | Эффект |
|----------|--------|
| Квиз шёл **раньше** тарифов и направлений | Клиент выбирает вслепую |
| Нет развилки **Такси / Доставка** | Путаница: водитель vs курьер |
| Классы Яндекс (эконом…) **после** тарифов парка | Нарушена логика «сначала куда ездить, потом как оформляться» |
| «Как подключиться» внизу страницы | Нет ориентира в начале |
| Навигация: квиз / услуги / FAQ подряд | Перегруз, нет сценария |
| Hero CTA сразу в квиз | Перескакивает знакомство и направления |

## Целевая последовательность блоков (внедрено)

1. **Hero + акция** — оффер и вход  
2. **О парке** (`#about`) — доверие, цифры  
3. **Как подключиться** — 5 шагов, карта пути  
4. **Направления** (`#directions`) — Такси или Доставка  
5. **Классы заказов** (`#yandex-tariffs`) — эконом → премиум → мост к доставке  
6. **Оформление в парке** (`#tariffs`) — самозанятый / ИП / трудовой + тизер курьера  
7. **Сравнение** → **Квиз** — помощь в выборе  
8. Трудовой подробно → требования → услуги  
9. Отзывы → FAQ → **Заявка** → контакты  

## KPI пути

- Клик «Такси» → доскролл до `#yandex-tariffs` / `#tariffs`  
- Клик «Доставка» → `/courier/`  
- Доля заявок с UTM после прохождения воронки
