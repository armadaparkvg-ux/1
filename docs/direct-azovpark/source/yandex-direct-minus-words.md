# Минус-фразы Яндекс Директ — парк «Армада»

Дата: 18.07.2026  
Основание: SEO/оффер сайта park-armada.ru + семантика ключей

## Кого берём (целевой лид)
Водитель с **гражданством РФ**, 21+, стаж 3+, хочет **подключиться к Яндекс Такси через парк**: самозанятый / ИП / трудовой, ФГИС, ОСГОП. Удалённо, своё авто (парк авто не сдаёт).

## Кого режем (почему минусуем)

| Кластер | Почему нецелевой |
|---------|------------------|
| Пассажир / заказ такси | Ищет поездку, не парк |
| Вакансии / HH / курьер | Ищет работу сотрудником, не подключение водителя |
| Скачать приложение | Нужен Яндекс Про, не заявка в парк |
| Аренда авто / без своего авто | На сайте нет аренды «под ключ» |
| Другие агрегаторы / еда / доставка | Чужой продукт |
| Грузовое / газель | Не легковое такси парка |
| Автошкола / права / ГИБДД | Не услуга подключения |
| Франшиза / открыть парк | B2B «свой бизнес», не водитель |
| Курсы / бухгалтерия / API | Инфошум, не лид |
| Иностранцы / без РФ | На сайте отказ: только гражданство РФ |

## 3. Не минусовать (частые ошибки)

| Фраза | Почему оставить |
|-------|-----------------|
| отзывы | на бренде нужны |
| официальный | доверие |
| комиссия | целевой коммерческий интент |
| самозанятый / ип / трудовой | ядро оффера |
| фгис / осгоп / лицензия | ваши услуги |
| банкротство / пособие / 2ндфл | целевой сегмент ТК |
| вывод / моментальный | целевой ИП/самозанятый |
| работа в яндекс такси | **осторожно:** это ключ ядра; минусуйте только «работа в яндексе» (офис), не «работа в яндекс такси» |

### Группа «Бренд»
Минуса мягче. **Не** ставьте: отзывы, адрес, телефон, официальный сайт.  
Можно:
```
вакансия
курьер
франшиза
```

## 5. Как применить в Директе

1. Кампания Поиск → Параметры → Минус-фразы → вставить блок из раздела 1.  
2. Кампания РСЯ → раздел 1 + раздел 2.  
3. Через 7–14 дней: Поиск → Отчёт «Поисковые запросы» → всё нецелевое → в минуса.  
4. Цель оптимизации: заявка / квиз / звонок — не клики.

---

## 6. SEO-вывод (кратко)

Сайт ранжируется и продаёт **подключение водителя к парку**, не поездки и не вакансии.  
Самые дорогие нецелевые кластеры в этой нише: **пассажир**, **скачать приложение**, **аренда авто**, **вакансии/курьер**, **грузовое**, **иностранцы**. Их минусование сильнее всего поднимает долю целевых лидов при том же бюджете.
