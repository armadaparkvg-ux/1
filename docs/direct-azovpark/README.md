## Как загрузить в кабинет

Нужен вход в Яндекс ID логина **azovpark**. Без сессии кабинет открыть нельзя.

### Вариант A — Директ Коммандер (предпочтительно)

1. [Скачать Коммандер](https://yandex.ru/project/commander/new).
2. Войти как `azovpark`.
3. Кампании → Импорт → файл `import/commander-azovpark-search.csv` (UTF-8, разделитель `;`).
4. Проверить соответствие колонок: название кампании, комбинаторное объявление, ссылка, быстрые ссылки.
5. Регион: Россия. Не ставить служебные URL (`/go/fleet/`, `/llms.txt`, `/courier/`).
6. После импорта: визитка с телефоном `+7 918 052-10-22`, часы 8:00–21:00.
7. Привязать счётчик Метрики `110811547`.
8. Кампании **не включать**, пока не пройдена модерация и не задан недельный бюджет.

### Вариант B — Мастер кампаний (ссылка из запроса)

Если остаётесь в [wizard](https://direct.yandex.ru/wizard/overview/?ulogin=azovpark), не скармливайте мастеру одну главную на все запросы. Создайте **отдельные** кампании по таблице выше, тексты берите из `import/ads.md`, ключи — из `import/campaign-url-map.csv`.

Порядок в мастере для П4:

1. Продвижение сайта → `https://park-armada.ru/trudovoj-dogovor/`
2. Регион: Россия
3. Цель: заявки (мессенджер / `click_labor_apply`), не сырой клик
4. Бюджет: ~10–14 тыс. ₽/нед на старте только П4, либо доля 35–40% от общего
5. Заменить автотексты на блок **labor** из `ads.md`
6. Быстрые ссылки набора П4 (тарифы → FAQ → 2‑НДФЛ → ФГИС)
7. Вставить минус-фразы из `minus-taxi-campaigns.txt`
8. Расписание 08:00–21:00 Мск
9. Повторить для П2, П1, П10…

### После модерации

1. Стратегия: клики + max CPC из таблицы.
2. Корректировки: смартфоны +10…+20%, планшеты −50%, возраст 18–24 −50%.
3. Через 15–30 заявок на кампанию — оплата за конверсии:  
   П4 `click_labor_apply` + `lead_messenger`;  
   П2/П3/П10 `lead_messenger` + `visit_fleet_go`.
4. РСЯ не больше 10–15% и только после стабильного Поиска.
