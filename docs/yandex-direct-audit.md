## 2. Аудит посадочной (контент / UX / конверсия)

### Сильные стороны
- Чёткое УТП: комиссия **от 1,9%**, активация **1,5–2 ч**, работа по РФ.
- Три оффера: парковый самозанятый / парковый ИП / трудовой договор (3%+300₽, 5%+100₽, 6%).
- Доп. услуги с ценой: ФГИС **3500₽/5 лет**, ОСГОП **3400₽/год**.
- CTA в мессенджеры + телефон; FAQ и JSON-LD готовы под SEO.
- Ограничения честно указаны (гражданство РФ) — меньше нецелевых заявок.

### Слабые стороны для платного трафика
| Зона | Риск | Рекомендация |
|------|------|--------------|
| Один лендинг на все интенты | Размытие релевантности объявление→страница | Отдельные URL/якоря под кампании (`/#tariffs`, `/#labor-contract`, `/#services`) или мини-лендинги |
| Нет явного гео в оффере | Дороже клик в регионах | В объявлении: «по всей России / удалённо» |
| Слабые социальные доказательства в hero | Ниже CR | Отзывы, скрины выплат, «3500+ водителей» ближе к CTA |
| Заявка только мессенджер | Часть аудитории бросает | Оставить + быстрый `tel:` как сейчас; для Директа — цель на звонок |
| Бренд «Армада» малоизвестен | Низкий brand search | Кампания на бренд + парковые ключи |
| Нет квиза «подобрать тариф» | Упущенный CR | Квиз 3–4 шага → мессенджер |

### Соответствие оффера рекламе (обязательно для модерации)
Писать в объявлениях **только факты с сайта**:
- Комиссия парка от **1,9%** (самозанятый / ИП)
- Трудовой: **3%+300₽ / 5%+100₽ / 6% без списаний**
- ФГИС **3500₽ / 5 лет**, ОСГОП **3400₽ / год**
- Активация **1,5–2 часа**
- Гражданство **РФ**, возраст **21+**, стаж **3+**
- **Не обещать** фиксированный заработок «от N ₽/день» без доказательств

## 3. Целевая аудитория (сегменты для Директа)

### A. Парковый самозанятый (ядро, ~40–50% бюджета на старте)
- **Кто:** водители на своём авто, уже в такси или новички; хотят низкую комиссию парка.
- **Возраст:** 25–50
- **Боль:** высокий % парка, долгая регистрация, «непонятные списания».
- **Триггер:** «1,9%», «быстрое подключение», «помощь с документами».
- **Посадка:** `/#tariffs` + форма самозанятого / заявка в MAX/Telegram.

### B. Парковый ИП (~15–20%)
- **Кто:** превысили лимит НПД / хотят моментальный вывод / работают «как бизнес».
- **Триггер:** «моментальный вывод», «ИП в структуре парка», «1,9%».
- **Посадка:** `/#tariffs` (блок ИП).

### C. Трудовой договор / ТК РФ (~20–25%)
- **Кто:** нужна «белая» занятость, банкротство, пособия, подтверждение дохода.
- **Триггер:** «по ТК РФ», «налоги платит парк», три схемы комиссии.
- **Посадка:** `/#labor-contract`.

### D. Лицензия ФГИС + ОСГОП (~10–15%, отдельные кампании)
- **Кто:** авто ещё не в реестре / нужна страховка для работы.
- **Триггер:** цена и срок («3500₽ на 5 лет», «1–3 дня»).
- **Посадка:** `/#services`.

### E. Переход из другого парка (ретаргет + РСЯ)
- **Триггер:** ниже комиссия, скорость смены парка, поддержка 8:00–21:00.

### Нецелевая аудитория
Нет гражданства РФ; возраст &lt; 21 / стаж &lt; 3 лет; пассажиры («заказать такси»); курьеры пешие; аренда авто (если не даёте).

### Гео и устройства
- Гео: Россия (удалённо) или топ-регионы по Wordstat.
- Mobile-first; ставки выше 08:00–21:00 Мск.
