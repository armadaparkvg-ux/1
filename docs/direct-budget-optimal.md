# Бюджет и ставки Яндекс Директ — парк «Армада»

Дата: 2026-07-25  
Цель: быть в топе по **целевым** запросам и не слить бюджет.

---

## 1. Главный принцип

| Не делать | Делать |
|-----------|--------|
| «Всегда спецразмещение / 1 место любой ценой» | Топ‑1–3 по **ядру** (СМЗ, трудовой, бренд) |
| Один большой бюджет на всё | Отдельные кампании + потолки |
| Оптимизация «за клики» на старте | Через 7–14 дней — за **заявки** (`click_labor_apply`, `lead_messenger`, `visit_*`) |
| РСЯ = 50% бюджета сразу | РСЯ ≤ 15–20% после стабильного Поиска |

«Быть в топе» = **доля показов в спецразмещении / топ‑1–3 ≥ 50–70% по высокоинтентным ключам**, а не 100% по всем запросам.

---

## 2. Стартовый бюджет (рекомендация)

Ориентир для теста **на всю Россию**, расписание 08:00–21:00 Мск:

| Уровень | Неделя | День | Когда |
|---------|--------|------|--------|
| Минимум (тест) | **21 000 ₽** | ~3 000 ₽ | проверить ключи и CR |
| Рабочий | **35 000–49 000 ₽** | **5–7 000 ₽** | основной режим |
| Рост | **70 000+ ₽** | 10 000+ ₽ | когда CPL стабилен |

Если бюджет меньше 3 000 ₽/день — **не включайте всё сразу**: только П2 (самозанятый) + бренд П6.

### Распределение дневного бюджета (рабочий режим ~6 000 ₽/день)

| Кампания / группа | Доля | ₽/день | Зачем |
|-------------------|------|--------|--------|
| **П2 Самозанятый** | 35–40% | 2 100–2 400 | ядро, самый чистый лид |
| **П4 Трудовой** | 20–25% | 1 200–1 500 | отдельная посадка, дороже ключ |
| **П1 Подключение** | 10–15% | 600–900 | общие «подключиться» |
| **Доставка курьер** | 10–15% | 600–900 | отдельный продукт |
| **П3 ИП** | 5–8% | 300–500 | уже узкий сегмент |
| **П5 ФГИС / ОСГОП** | 5% | 300 | доп. услуга |
| **П6 Бренд** | 3–5% | 200–300 | дёшево, защитить имя |
| **РСЯ + ретаргет** | 10–15% | 600–900 | только после 20+ заявок с Поиска |

Итого при 6 000 ₽/день ≈ **180 000 ₽/мес** — нормальный «не слить, но учиться» уровень для ниши таксопарков.

## 3. Стратегия ставок (что выбрать в Директе)

### Неделя 1–2 (обучение)
- Тип: **«Максимум кликов»** или **«Оптимизация кликов»**
- Недельный бюджет = 7 × дневной потолок
- Ограничение цены клика (важно):
  - Самозанятый / подключение: **макс. CPC 45–70 ₽**
  - Трудовой: **макс. CPC 55–90 ₽**
  - Курьер: **макс. CPC 35–60 ₽**
  - Бренд: **макс. CPC 15–25 ₽**
  - РСЯ: **макс. CPC 15–30 ₽**

Так вы не улетите в топ‑1 по мусорным аукционам.

### С недели 3 (когда есть 15–30 конверсий на кампанию)
- Перейти на **«Оптимизация конверсий»** / оплату за конверсии
- Цели: `lead_messenger` + `click_phone` + для П4 `click_labor_apply` + `visit_trudovoj`
- Целевая цена конверсии (CPL) ориентир:
  - Самозанятый: **400–900 ₽** за заявку
  - Трудовой: **500–1 200 ₽**
  - Курьер: **350–800 ₽**
  - Если CPL выше 1 500 ₽ 3 дня подряд — резать ключи / объявления, не поднимать бюджет

### Про «топ»
В настройках показов:
- Поиск: **спецразмещение / гарантированные** — да
- Не включать «показывать только на 1 месте» постоянно
- Смотрите отчёт **«Доля выигранных показов» / позиция**: цель **ср. позиция 1,3–2,5** по ядру

## 4. Как не слить бюджет (правила)

1. **Отдельные кампании** — Поиск ≠ РСЯ. На РСЯ свой маленький бюджет.
2. **Минус-слова** с первого дня (см. `yandex-direct-minus-words.md` + блок для трудового).
3. **Расписание 08:00–21:00 Мск** (+ буфер 07:00–22:00). Ночью клики дороже и хуже конвертят.
4. **Корректировки ставок:**
   - Моб. телефоны: **+10…+20%** (водители с телефона)
   - Планшеты: **−50…−100%**
   - Возраст &lt; 18 / 18–24: **−50…−100%** (если нет 21+)
   - Пол: без урезания на старте
5. **Не масштабировать** бюджет больше чем **+20–30% раз в 3–4 дня**, если CPL в норме.
6. **Ежедневно (15 мин):** отключить ключи с кликами без заявок и CTR &lt; 3% на Поиске (после 50+ показов).
7. **Не смешивать** самозанятый / трудовой / курьер в одной группе — сжигает релевантность и цену.
8. Гео: на старте **РФ** ок; если дорогой клик — оставить топ‑города + «удалённо» в тексте, не весь мир интересов РСЯ.

---

## 5. Пороги «стоп / масштаб»

| Метрика | Норма (Поиск) | Действие |
|---------|---------------|----------|
| CTR | ≥ 5–8% | &lt; 3% → править объявления |
| Отказы (Метрика) | ≤ 40–50% | выше → проверить посадку/UTM |
| Заявка / клик | ≥ 3–7% | ниже 2% → оффер/минусы |
| CPL | см. выше | &gt; 1,5× цели 3 дня → резать |
| Доля в топ‑1–3 | 50–70% ядро | &lt; 30% при хорошем CPL → +бюджет/ставка аккуратно |

## 6. Оптимальная схема «в топе и не слить» (итог)

```
День 1–14
  Поиск: П2 40% + П4 20% + П1 10% + курьер 10% + остальное 10%
  РСЯ: выкл или 5–10% только ретаргет
  Стратегия: клики + жёсткий max CPC
  Бюджет: 5–7 тыс ₽/день

День 15+
  Стратегия: конверсии (заявки)
  РСЯ ретаргет: до 15%
  Бюджет растить только если CPL в коридоре
  Топ держать по ядру (СМЗ 1,9%, трудовой, бренд), не по мусорным ключам
```

**Формула безопасного дневного бюджета:**  
`CPL_цель × нужное_число_заявок_в_день × 1,3 (запас на обучение)`  
Пример: хотите 6 заявок/день при CPL 700 ₽ → `6 × 700 × 1,3 ≈ 5 500 ₽/день`.

## 7. Что выставить руками в кабинете прямо сейчас

1. Недельный бюджет кампании Поиск = **7 × ваш дневной потолок**.  
2. Max CPC по группам — как в §3.  
3. Расписание 08:00–21:00 Мск.  
4. Цели Метрики привязать к кампаниям.  
5. РСЯ — отдельная кампания, бюджет **не больше 15%**.  
6. П2 и П4 не объединять.

Точные цифры CPC по вашему аукциону Директ покажет в прогнозе при добавлении ключей — сверьте с потолками выше и урежьте, если прогноз &gt; max CPC.
