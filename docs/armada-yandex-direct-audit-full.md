## 3. Целевая аудитория (сегменты для Директа)

### A. Парковый самозанятый (ядро, ~40–50% бюджета на старте)
- **Кто:** водители на своём авто, уже в такси или новички; хотят низкую комиссию парка.
- **Возраст:** 25–50
- **Боль:** высокий % парка, долгая регистрация, «непонятные списания».
- **Триггер:** «1,9%», «быстрое подключение», «помощь с документами».
- **Посадка:** `/#tariffs` + форма самозанятого / заявка в MAX/Telegram.
- **Интересы/ретаргет:** Яндекс Про, авто, подработка, «Мой налог».

### B. Парковый ИП (~15–20%)
- **Кто:** превысили лимит НПД / хотят моментальный вывод / работают «как бизнес».
- **Боль:** лимит 2,4 млн, сложный переход с самозанятости.
- **Триггер:** «моментальный вывод», «ИП в структуре парка», «1,9%».
- **Посадка:** `/#tariffs` (блок ИП).

### C. Трудовой договор / ТК РФ (~20–25%)
- **Кто:** нужна «белая» занятость, банкротство, пособия, подтверждение дохода для Яндекса/банков.
- **Боль:** нельзя/невыгодно самозанятость; нужны 2-НДФЛ / договор.
- **Триггер:** «по ТК РФ», «налоги платит парк», три схемы комиссии.
- **Посадка:** `/#labor-contract`.

### D. Лицензия ФГИС + ОСГОП (~10–15%, отдельные кампании)
- **Кто:** авто ещё не в реестре / нужна страховка для работы.
- **Триггер:** цена и срок («3500₽ на 5 лет», «1–3 дня»).
- **Посадка:** `/#services` + кнопка проверки ФГИС.

### E. Переход из другого парка (~ретаргет + РСЯ)
- **Кто:** уже работают, ищут ниже комиссию / лучше поддержку.
- **Триггер:** сравнение %, скорость смены парка, поддержка 8:00–21:00.

### Нецелевая аудитория (минус + отказ в заявке)
- Нет гражданства РФ  
- Возраст &lt; 21 / стаж &lt; 3 лет  
- Ищут заказ такси (пассажиры)  
- Ищут аренду авто «под ключ» без своего авто (если парк не даёт авто — минусовать)  
- Вакансии курьера / пеший курьер (если не оказываете)  
- «Скачать Яндекс Про» без интента подключения к парку  

### Гео и устройства
- **Гео старт:** Россия (удалённое оформление) **или** топ-регионы спроса: Москва и МО, СПб и ЛО, Краснодарский край, Ростов, Рязань, Воронеж, Казань, Екатеринбург — уточнить по Wordstat и фактическим заявкам.
- **Устройства:** mobile-first (80%+ кликов типично для ниши).
- **Расписание:** ставки выше 08:00–21:00 Мск (часы консультации).
