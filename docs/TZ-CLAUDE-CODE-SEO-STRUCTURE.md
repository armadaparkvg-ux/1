## 2. Как проверять (обязательно)

Проверяйте **сырой HTML**: `curl -s`, `curl -sI`, Ctrl+U в браузере.

**Нельзя** опираться на конвертер «страница → статья» (он вырезает `<html lang>`, `<script>`, `<meta>`). Если конвертер пишет «нет lang / нет JSON-LD», а в `curl` они есть — верить `curl`.

Локально после правок:

```bash
npm run build:static && node scripts/check-seo-tz.mjs
```

Скрипт — минимум. Это ТЗ шире: структура, воронка, `/license/`, крошки, анкоры.

На live — `curl` **всех URL из sitemap** (45 адресов, §4).

Маркер сборки в исходнике главной:

- есть `id="jsonld-organization"`
- в том же JSON-LD видно `"@type": "Organization"` (после двоеточия пробел: pretty-print)

Валидаторы (если есть сеть):

- https://validator.schema.org/ — 0 ошибок на `/`, одной статье блога, `/goroda/moskva/`
- Не ставить схемы из «советов Google», которых нет в §6

## 5. SEO: title, OG, разметка

Все `generateMetadata` только через `pageMetadata()` в `src/lib/seo-meta.ts`. Иначе пропадёт `og:image`.

### Title (A-2)

- Ни один title из sitemap **> 60** символов.
- «Армада» не дважды в одном title.
- Хвост ` | Армада` — только если в title ещё нет подстроки «армада» (любой регистр).
- **Блог (`blog: true`) — хвоста никогда нет.**
- Москва: `Подключение к Яндекс Такси в Москве | Армада`
- `/o-parke/`: `О парке «Армада» — знакомство с таксопарком` (без хвоста).
- Главная: `Подключение к Яндекс Такси и Доставке — таксопарк «Армада»`
- Description главной начинается с **«Удалённо по России»**, длина **≤ 160**.

### Open Graph (A-3)

На каждой индексируемой странице: `og:type`, `og:image`, `og:image:width` 1200, `og:image:height` 630, `og:locale` `ru_RU`, `og:site_name`.

- По умолчанию `/og.jpg` (файл физически 1200×630).
- Блог: `og:type=article` + `article:published_time`.
- `/taxi/` → `taxi-premium-hero.webp`
- `/trudovoj-dogovor/` → `labor-limit-hero.jpg`
- `/delivery/` → `delivery-hero-banner.jpg`
- `/license/` и `/osgop/` — **разные** картинки и разные alt (`service-license.jpg` / `service-osgop.jpg`).

### JSON-LD (B)

Pretty-print. Id: `jsonld-organization`, `jsonld-website`, `jsonld-page`.

| Тип | Где | Ограничения |
|---|---|---|
| Organization | все страницы, `<head>` | телефон `+7-918-052-10-22`; без email; адрес без «кв. 213»; logo `https://park-armada.ru/icon.svg` |
| WebSite | layout | `@id` `#website` |
| BreadcrumbList | блог + города + визуальные крошки | у **последнего** пункта нет `item` |
| Article | 22 статьи | headline ≤ 110 |
| Service | только `/taxi/`, `/trudovoj-dogovor/`, `/delivery/`, `/license/` | **без `offers`** |
| Город | WebPage + BreadcrumbList | без Service / FAQ |

Визуальный FAQ на HTML **оставить**. Микродата крошек: `itemType="https://schema.org/BreadcrumbList"` в `src/components/breadcrumbs.tsx`.

`robots.txt`: нет строки `Host:`. Список AI-ботов и Sitemap не сокращать и не расширять без причины из этого ТЗ.

Alt: `tariff-labor.jpg` / `tariff-ip.jpg` / `tariff-selfemployed.jpg` — по смыслу картинки. `hero-bg` и пиксель Метрики — `alt=""`.

Оферта: разделы 1.–13. как H2, пункты как `<p>`, без мусорной пунктуации.

## 6. Структура и логика просмотра (проверить как пользователь)

Цель: водитель за один экран понимает, куда идти, и не теряется между такси, трудовым, лицензией и доставкой.

### Главная `/`

Должна отвечать только «какое направление?», не быть простынёй «о парке».

Проверить в HTML:

1. Один H1 про подключение к Яндекс Такси и Доставке.
2. Блок «Что вам нужно на сайте» со ссылками на `/taxi/`, `/trudovoj-dogovor/`, `/license/`, `/osgop/`, `/delivery/`, `/goroda/`.
3. Карточки направлений `#directions`: трудовой, такси, доставка, лицензия ФГИС, ОСГОП.
4. Блок «Как подключиться к парку» — нумерованные шаги (HTML `<ol>` / «Шаг N»), **без** HowTo JSON-LD.
5. FAQ — превью, ссылка на `/faq/`.
6. Нет аренды авто. Комиссия «от 1,9%», поддержка «8:00–21:00», активация «10–15 минут» — только эти опоры, без «0%» и «24/7».

### Шапка

На широком экране рабочие пути: Такси, Трудовой, Доставка, Лицензия, ОСГОП, Города + кнопка «Поиск».

В мобильном меню допустим полный список, включая О парке, FAQ, Акции, Контакты.

Нельзя, чтобы 11 пунктов шапки имели одинаковый вес и прятали лицензию / трудовой.

### Пульт сайта (поиск)

Это **поиск по сайту**, не нейросеть и не ChatGPT.

Проверить:

- кнопка «Поиск» в шапке, `aria-label` есть;
- ответы только из страниц / FAQ / статей (модули `src/lib/site-index.ts`, `src/lib/site-search.ts`);
- нет обещания «ИИ рассчитает заработок»;
- если ответа нет — путь в MAX, без выдуманных цифр.

Не подключать внешний LLM.

### `/license/` — процесс оформления (источник правды)

В тексте и в шагах, по порядку:

1. Написать в чат (MAX основной, Telegram запасной).
2. Прислать фото авто и СТС **с двух сторон**.
3. Дождаться документ **1–3 дня** в зависимости от региона подачи.
4. Проверить документ в реестре ФГИС.
5. Оплатить **3 500 ₽** — **после** проверки, не до неё. Срок внесения — 5 лет.

Запрещено на этой странице: путевые листы; копипаст с fgis.online; «оплата сразу»; выдуманный срок «в день обращения по всей России».

Title (после `pageMetadata`, с хвостом): `Лицензия такси ФГИС: оформить выписку за 1–3 дня | Армада` — не длиннее 60.

H1 отвечает «оформить выписку». Первый абзац после H1 — процесс, не обзор рынка.

### Воронка между страницами

| Страница | Куда человек должен суметь уйти |
|---|---|
| `/taxi/` | трудовой, лицензия, доставка |
| `/trudovoj-dogovor/` | такси, FAQ / чат поддержки (трудовой **без** авторегистрации Fleet) |
| `/delivery/` | такси, города |
| `/license/` | такси, ОСГОП, статья проверки ФГИС |
| `/osgop/` | лицензия, такси |

Sticky на мобильном:

- `/license/` — «Оформить лицензию», заявка темы «лицензия ФГИС»;
- `/osgop/` — «Оформить ОСГОП»;
- `/trudovoj-dogovor/` — трудовой, не форма Fleet;
- `/taxi/` и `/delivery/` — выбор формата / регистрация.

### Общие условия (все 10 городов + коммерческие, если блок есть)

Гражданство РФ; трудовой только через поддержку; паспорт / права / СТС / ИНН / СНИЛС / фото авто с 4 сторон (это качество снимка, не замена «СТС с двух сторон» в процессе ФГИС); ФГИС 3500 ₽ / 5 лет / 1–3 дня; ОСГОП 3400 ₽/год; тарифы 3%+300 / 5%+100 / 6%.

### Доступность каркаса

- `<html lang="ru">`
- skip-link «Перейти к содержимому» → `#main`
- иконки без текста — `aria-label`
- фокус виден (кольцо accent), нет `outline: none` без замены

## 8. Что чинить, чего не чинить

**Чинить**, если сломано относительно этого ТЗ: title > 60, дубль бренда, нет og, FAQPage затесался, H1=H2 на FAQ, регион в анкоре города, пропал процесс лицензии, 301 не срабатывает, Organization с email или кв. 213, Service с offers, хвост `| Армада` на статье.
