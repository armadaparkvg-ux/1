# Как дать агенту автономию (без вашего участия на каждом шаге)

## Уже есть (ничего включать не нужно)

В этой Cloud VM агент **уже может сам**:
- ставить пакеты (`apt`, `pip`, Docker при необходимости)
- скачивать зависимости из интернета (сеть не ограничена)
- запускать сервер, тесты, делегировать Claude/GPT

То есть «доступ на скачивание программ» у меня **уже есть**.

## Чего не хватает (задаёте 1 раз)

Секреты нельзя выдумывать — их нужно положить в Cursor **один раз**:

| Секрет | Зачем |
|---|---|
| `LLM_API_KEY` | живой диалог (OpenAI / DeepSeek) |
| `LLM_BASE_URL` | например `https://api.deepseek.com` |
| `LLM_MODEL` | например `deepseek-chat` |
| `TELEGRAM_BOT_TOKEN` | бот в Telegram |
| `MAX_WEBHOOK_SECRET` | webhook MAX |
| (опционально) логин AmoCRM | обучение на живых чатах |

### Куда положить (рекомендуется)

1. Откройте Cloud Agent / Environment в Cursor.
2. Раздел **Secrets** / **Environment variables**.
3. Добавьте ключи из таблицы выше.
4. Новые агенты подхватят их автоматически (скрипт `scripts/bootstrap.sh` синхронизирует в `.env`).

Не присылайте ключи в чат, если можно избежать — лучше Secrets.

## Автоустановка без вас

В репозитории уже настроено:

- `.cursor/environment.json` → `install` + `start`
- `scripts/bootstrap.sh` — ставит Python/зависимости, проверяет базу
- `scripts/start_services.sh` — поднимает ИИ-сервер на `:8080`

После сохранения Environment / следующего запуска агента всё поднимется само.

## Что сделать вам прямо сейчас (5 минут, один раз)

1. Создать ключ DeepSeek или OpenAI → положить в Secrets как `LLM_API_KEY`.
2. (Опционально) создать бота у `@BotFather` → `TELEGRAM_BOT_TOKEN`.
3. Больше ничего: дальше агент сам ставит, обновляет и запускает.

Без облачных ключей агент сам ставит **Ollama + qwen2.5:3b** и отвечает локально (+ эталонные ответы менеджера).
