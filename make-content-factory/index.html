API соцсетей

Ключи хранятся локально в браузере · можно выгрузить в Make

Instagram Graph API · VK API · YouTube Data API v3 · TikTok Content Posting API. После сохранения нажмите «Скачать для Make» — получите файл переменных для сценариев CF-01…CF-07. Токены не уходят на сервер: только localStorage этого браузера.

Почему Factory, а не «ещё Buffer»

Берём сильное, отбрасываем слабое

Взяли

  • Простоту очереди у Buffer
  • Визуальное планирование у Later
  • Согласования у Hootsuite / Planable
  • VK и RSS у SMMplanner
  • Массовый импорт и API-мышление у Postmypost
  • Повтор контента у SocialBee

Не копируем

  • Серые мультиаккаунты и прокси
  • Один текст на все сети
  • Тяжёлый корпоративный listening
  • Прямой репост ссылок в VK (убивает охват)
