CF-01 Publisher Core

    Platforms

    Что делает каждая ветка

    В роутере фильтр по колонке platforms: instagram,vk,youtube,tiktok.

    Instagram

    • POST /media (REELS)
    • Sleep / poll FINISHED
    • POST /media_publish
    • Лимит ~100/сутки

    VK

    • video.save → upload_url
    • multipart upload файла
    • wall.post + publish_date
    • Только нативный файл

    YouTube

    • videos.insert resumable
    • private + publishAt
    • Shorts = 9:16 short
    • Квота ~6 upload/день

    TikTok

    • creator_info/query
    • video/init PULL_FROM_URL
    • status/fetch
    • Нужен App Audit
